# Инструкция по использованию API «Колледж.Банк»

## Назначение API
API предназначено для программного получения и создания публикаций на платформе обмена навыками студентов.

## Запуск проекта
1. Убедитесь, что в корне проекта лежит база `database.db`.
2. Запустите сервер: `php -S localhost:8000 -t public`

## Эндпоинты

### 1. Получение списка публикаций
**Запрос:** `GET http://localhost:8000/api/offers.php`
**Параметры:** нет.
**Ответ:** `200 OK`, JSON-массив.

### 2. Получение одной публикации по ID
**Запрос:** `GET http://localhost:8000/api/offers.php?id=5`
**Параметры:** `id` (integer, обязательный).
**Ответ:** `200 OK` (JSON-объект) или `404 Not Found`.

### 3. Создание публикации
**Запрос:** `POST http://localhost:8000/api/offers.php`
**Заголовок:** `Content-Type: application/json`
**Тело (JSON):**
```json
{
  "title": "Помощь с базами данных",
  "description": "Помогу разобраться с SQL",
  "user_id": 1,
  "type": "help"
}
